Connect GitHub

記事を公開するための「鍵」です。この端末のブラウザにだけ保存され、ほかの人には見えません。

トークンの作り方
  1. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access で Only select repositories → fuukazin-rgb/links だけを選ぶ
  3. Permissions の Contents を Read and write にする
  4. 作成されたトークンをここに貼り付けて「保存して接続」
