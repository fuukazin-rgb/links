How to Start

はじめ方

インストールしてすぐ、7日間の無料トライアルで試せます。

  1. Chromeに追加

    Chromeウェブストアから拡張機能をインストールします。

  2. 無料トライアル開始

    7日間、全機能を試せます。

  3. ボタンを押して転記

    メルカリの商品ページで保存して、ほかのフリマの出品ページでボタンを押します。

  4. 気に入ったら購入

    Gumroadで月額または年額プランを購入し、届いたライセンスキーを入力します。

FAQ

Questions

よくある質問

Qスマホでも使えますか？

Chrome拡張機能のため、パソコン版のGoogle Chrome（Windows・Mac）のみ対応しています。

Qメルカリのログイン情報は取得されますか？

取得するのは商品情報（タイトル・価格・説明文・画像）だけです。ログイン情報や個人情報は一切取得しません。

Qラクマ・Yahoo!フリマ・ヤフオクのアカウントは必要ですか？

はい、それぞれのサービスのアカウントが別途必要です。

Qトライアル終了後、自動で課金されますか？

自動で課金されることはありません。続けて使う場合は、月額または年額プランをご購入ください。

Q解約はいつでもできますか？

Gumroadのマイページから、いつでもすぐに解約できます。次回の更新日以降の請求は発生しません。

Qブランド名が入力されないことがあります。

Yahoo!フリマ・ラクマのブランドデータベースに登録されていないブランドがあります。「お探しのワードでは見つかりませんでした」と表示される場合は、各サイト側の仕様です。

Qライセンスキーが届きません。

購入後、登録したメールアドレスに自動で送信しています。まず迷惑メールフォルダを確認してください。見つからない場合は、もう一度購入せずに（二重請求になります）、メールかLINE公式アカウントでご連絡ください。確認してキーをお送りします。

Q出品アシスト Pro と 管理アシスト の違いは？

料金は同じです。出品アシスト Pro は転記に加えて、画像の一括ダウンロードと定型文が使えます。管理アシストは転記に加えて、商品管理DBと「売れた！」ボタンでの一括削除が使えます。
